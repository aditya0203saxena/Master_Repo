Detection pipeline

Face landmarks are tracked locally in the browser. Temporal filtering turns eye, gaze, eyebrow and mouth movement into intentional commands. Calibration should be performed for each user.

Prototype only — not a medical device. Detection thresholds should be calibrated for each user before assistive use.

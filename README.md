# Hackathon Master Repo

A reusable full-stack starter for hackathons.

## Planned stack

- Next.js + TypeScript
- Tailwind CSS + shadcn/ui-ready component structure
- Supabase-ready authentication/database integration
- AI provider integration hooks
- ESLint + formatting conventions
- Vercel-ready deployment
- Reusable UI, API, auth, and utility patterns

## Setup

1. Install Node.js 20+.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env.local`.
4. Fill in the variables you need.
5. Run `npm run dev`.

## Hackathon workflow

1. Start from this repository.
2. Define the problem and core user flow.
3. Reuse the existing layout, UI primitives, auth, database helpers, and API patterns.
4. Build the MVP first, then polish UX and demo-critical flows.
5. Deploy to Vercel.

## Environment

See `.env.example` for the supported configuration placeholders.
